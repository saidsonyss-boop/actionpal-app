# تطبيق مجموعة العمل من أجل فلسطينيي سورية — نسخة بخادم وسيط

تطبيق إخباري يعرض آخر الأخبار من موقع [actionpal.org.uk](https://actionpal.org.uk)
عبر **خادم Node.js وسيط** يتصل بواجهة WordPress الخاصة بالموقع من جهة الخادم،
فلا يتعرض لقيود CORS التي تواجه الاتصال المباشر من متصفح المستخدم.

## البنية

```
.
├── server.js          # الخادم: يجلب الأخبار من actionpal.org.uk ويخزّنها مؤقتاً
├── package.json
└── public/
    ├── index.html     # واجهة التطبيق (تتصل بـ /api/news على نفس الخادم)
    └── logo.png        # شعار المنظمة
```

## التشغيل محلياً

يتطلب Node.js إصدار 18 أو أحدث (لدعم `fetch` المدمج).

```bash
npm install
npm start
```

ثم افتح المتصفح على:

```
http://localhost:3000
```

## كيف يعمل

1. المتصفح يطلب `/api/news` من خادمك أنت (وليس من actionpal.org.uk مباشرة).
2. خادمك يتصل بـ `https://actionpal.org.uk/wp-json/wp/v2/posts` من جهة الخادم — هذا اتصال خادم-لخادم لا تُطبَّق عليه قيود CORS إطلاقاً.
3. الخادم يبسّط البيانات (العنوان، الصورة، التصنيف، الرابط، التاريخ) ويحتفظ بنسخة مؤقتة لمدة 5 دقائق لتخفيف الضغط على موقع المصدر.
4. إن فشل الاتصال بالموقع الأصلي، يُعاد آخر نسخة محفوظة إن وجدت، وإلا تظهر رسالة خطأ واضحة في الواجهة بدل بيانات وهمية.

## النشر على الإنترنت (لجعله متاحاً بشكل دائم)

هذا خادم Node.js عادي يمكن نشره على أي منصة استضافة تدعم Node. من أسهل الخيارات المجانية:

### الخيار الأول: Render.com
1. أنشئ حساباً على [render.com](https://render.com).
2. ارفع هذا المجلد إلى مستودع GitHub خاص بك.
3. من لوحة Render: **New → Web Service** واختر المستودع.
4. اضبط:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
5. اضغط Deploy. سيمنحك Render رابطاً عاماً دائماً مثل `https://your-app.onrender.com`.

### الخيار الثاني: Railway.app
نفس الخطوات تقريباً: اربط مستودع GitHub، Railway يكتشف Node.js تلقائياً وينشر المشروع.

### الخيار الثالث: خادمك الخاص (VPS)
```bash
git clone <رابط المستودع>
cd actionpal-news-app
npm install
npm install -g pm2
pm2 start server.js --name actionpal-app
```

## ملاحظات

- يمكنك تغيير مدة التخزين المؤقت من المتغير `CACHE_TTL_MS` في `server.js`.
- لإضافة تصنيفات فرعية (سوريا، الأردن، تركيا...) لاحقاً، يمكن تمرير معرّف التصنيف WordPress category ID إلى رابط `API_URL` مثل: `&categories=12`.
- الأرقام الإحصائية الحقيقية غير متوفرة عبر واجهة WordPress القياسية؛ إن أردت عرضها ستحتاج لإضافتها يدوياً أو عبر واجهة برمجية خاصة إن توفرت من المنظمة.
